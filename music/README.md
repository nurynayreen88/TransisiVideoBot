# Muzik TransisiVideoBot

Letakkan enam fail MP3 asal dalam folder ini dengan nama tepat:

- cinematic.mp3
- energetic.mp3
- happy.mp3
- luxury.mp3
- nature.mp3
- beauty.mp3

Sandaran asal: https://drive.google.com/drive/folders/18cvJcRn9j7xgRK9wYs8f6XLfSQr0WHOX

Kod bot membaca fail tempatan semasa menjana video; Render tidak membaca Google Drive peribadi secara langsung. Pilihan Auto: hybrid → happy, cinematic → cinematic, morph → energetic. MP3 sendiri mengatasi pilihan Auto. Jika fail tiada, bot memberi notis dan menjana tanpa muzik. Jangan deploy sehingga keenam-enam MP3 disertakan dalam imej Docker dan janaan diuji.
